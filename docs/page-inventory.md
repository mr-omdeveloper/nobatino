# فهرست صفحه‌های نوبتینو

شناسه‌های زیر در تحویل، بازبینی و گزارش تغییر استفاده می‌شوند. این فهرست نام صفحه‌ها را ثبت می‌کند؛ هدف هر صفحه، طراحی، محتوا، امکانات و جریان کار را تیم مسئول همان صفحه مشخص می‌کند.

| شناسه | صفحه | تیم مسئول |
| --- | --- | --- |
| `P01` | صفحهٔ اصلی و لندینگ | تعیین‌نشده |
| `P02` | صفحهٔ جست‌وجو | تعیین‌نشده |
| `P03` | صفحهٔ ورود | تعیین‌نشده |
| `P04` | صفحهٔ پنل کاربر | تعیین‌نشده |
| `P05` | صفحهٔ پنل پزشک | تعیین‌نشده |
| `P06` | صفحهٔ رزرو نوبت | تعیین‌نشده |
| `P07` | صفحهٔ پرداخت: درگاه فرضی `P07-payment-gateway.html`، نتیجهٔ موفق `P07-payment-success.html` و نتیجهٔ ناموفق `P07-payment-failure.html` | تعیین‌نشده |

نام تیم را پس از مشخص شدن مسئولیت ثبت کنید. همهٔ تیم‌ها از [سیستم طراحی](./design-system.md) و [الگوی مشترک تحویل صفحه](../llm-work-template-main/_framework/page-handoff.md) استفاده می‌کنند. شماره‌ها ترتیب پیمایش را تعیین نمی‌کنند.
